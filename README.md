# Thực Hành Thiết Kế Vi Mạch Số Với HDL


## Giới thiệu

Repository này tổng hợp các bài thực hành môn **Thiết kế vi mạch số với HDL** sử dụng ngôn ngữ **Verilog HDL** và phần mềm **Quartus II**.

Các bài tập được xây dựng và mô phỏng trên kit FPGA DE2, bao gồm các nội dung cơ bản đến nâng cao như:

- Mạch logic tổ hợp
- Bộ giải mã LED 7 đoạn
- Mạch đếm
- Clock & Timer
- Bộ cộng nhị phân
- Máy trạng thái FSM
- Thiết kế và kiểm thử trên FPGA
